# FIRM — Digital Production & Business Growth Agency ⚡

Официальный репозиторий и цифровой флагман агентства **FIRM**. 

Разработка сайтов, брендинг, продающие лендинги, инвестиционные презентации, кастомное программное обеспечение, технический и поисковый аудит, SEO-оптимизация, комплексное ведение соцсетей (SMM) и упаковка бизнеса под ключ.

---

## 🚀 Направления и услуги

1. **Разработка сайтов и веб-сервисов** — Корпоративные порталы, каталоги, экосистемы и сервисы с производительностью 90+ в Google PageSpeed.
2. **Брендинг и айдентика** — Позиционирование, логотип, фирменный стиль, брендбук, гайдлайны и Tone of Voice.
3. **Продающие лендинги (High-Conversion)** — Маркетинговые страницы с конверсией 8–22%, интерактивными квизами и интеграцией CRM.
4. **Презентации и Pitch Decks** — Инвестиционные деки, коммерческие предложения (КП) и презентации для привлечения капитала и закрытия B2B сделок.
5. **Разработка ПО и SaaS** — Кастомные платформы, CRM/ERP системы, Telegram Web Apps (TWA), интеграции по API.
6. **Аудит и SEO-оптимизация** — Технический аудит, аудит конверсии (CRO), сбор семантического ядра и вывод в ТОП Яндекса и Google.
7. **Ведение соцсетей и SMM** — Контент-стратегия, сценарии и съемка Reels / Shorts, визуал, таргетинг и воронки продаж.
8. **Комплексная упаковка бизнеса 360°** — Полная сборка компании: от смыслов и УТП до сайта, мерча, скриптов и сквозной аналитики.

## 🛠 Технологический стек

- **Frontend**: React 19, Tailwind CSS, Lucide Icons, Vite
- **Backend & API**: Node.js HTTP/Express API, REST, Telegram Bot notifications
- **DevOps & Cloud**: Docker (multi-stage alpine), Railway Cloud Platform, GitHub CI/CD

---

## 💻 Локальный запуск

1. Установка зависимостей:
   ```bash
   npm install
   ```

2. Запуск в режиме разработки:
   ```bash
   npm run dev
   ```

3. Сборка продакшн-бандла:
   ```bash
   npm run build
   ```

4. Запуск продакшн-сервера:
   ```bash
   npm start
   ```

Сервер будет доступен по адресу: `http://localhost:3000`.
